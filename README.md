# JagX AI

Grok-style multipurpose AI for Africa. Clean rebuild.

## Setup

1. Copy `.env.example` → `.env`
2. Add Supabase URL, anon key, OpenRouter key
3. `flutter pub get && flutter run`

## GitHub Secrets (CI)

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `OPENROUTER_API_KEY`
